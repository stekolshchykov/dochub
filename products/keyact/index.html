What you need to know

Apple's translation, word-analysis, dictionary and speech resources have different language coverage. Some need an initial download; not every Apple resource has an in-app installer. Related words are not guaranteed interchangeable synonyms, and Context is not a complete grammar checker. Optional online dictionary fallback and your HTTP actions require internet.

The interface is currently in English. Russian setup and troubleshooting help is available. The full local edition can run typed shell commands and use Accessibility; those capabilities are not part of the sandbox App Store edition.

For safe help, include the version, build, tool and selected languages—never private text, recordings or credentials. Open support.
